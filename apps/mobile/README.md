# OFFMAP Mobile

Expo app for iOS, Android, and Expo web preview.

From the repo root:

```bash
npm run mobile
npm run mobile:ios
npm run mobile:web
```

Or from this folder:

```bash
npm run start
npm run ios
npm run web
```

Environment variables used by the mobile app:

- `EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN`
- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_ANON_KEY`
